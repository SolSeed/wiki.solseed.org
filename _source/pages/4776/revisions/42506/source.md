This template is a version of [Template unavailable in the 2018 archive: tl — reflist] designed to show a reference section for a talk page discussion within a bordered box.

#### Usage
- [Template unavailable in the 2018 archive: tlx — reflist-talk; 2=close=1]

Optional:
- [Template unavailable in the 2018 archive: tlx — reflist-talk; 2=title=; 3=group=; 4=colwidth=; 5=refs=]

[Template unavailable in the 2018 archive: para — close; 1] is used to ensure that references from a previous section are not included in the current reference list. It must be used, except when any of the other parameters are included.

**Parameters**

- [Template unavailable in the 2018 archive: para — title] specifies the box title, defaults to References

The template honors these features of [Template unavailable in the 2018 archive: tl — reflist]:
- [Template unavailable in the 2018 archive: para — colwidth]
- [Template unavailable in the 2018 archive: para — refs]
- [Template unavailable in the 2018 archive: para — group]

 

The template should be placed after the discussion that includes the references, as it will include all references before the template.
