A personification is a type of metaphor in which an abstract concept is equated with a fictional person.  It is a useful device in fiction in that abstract concepts can be given an opportunity to explain themselves to an audience.  The insight of the SolSeed movement is that we can also develop emotional attachments to personifications which can be transferred to the concept itself.
