A movement is a [ValuesMovement](/ValuesMovement) if it makes assertions about the source of values and what the highest values are.  Most religions are [ValuesMovement](/ValuesMovement)s.

The [SolSeedMovement](/SolSeedMovement) is a [ValuesMovement](/ValuesMovement) because it asserts that all value derives from the basic [ValueJudgement](/ValueJudgement) that all [life](/life) is precious and good.

See also [SolSeed and Religion](/SolSeed_and_Religion).
