[[SolSeed]] < [[SolSeedMovement]] < [[ValuesMovement]] A movement is a [[ValuesMovement]] if it makes assertions about the source of values and what the highest values are. Most religions are [[ValuesMovement]]s. The [[SolSeedMovement]] is a [[ValuesMovement]] because it asserts that all value derives from the basic [[ValueJudgement]] that all [[life]] is precious and good. See also [[SolSeed and Religion]].
