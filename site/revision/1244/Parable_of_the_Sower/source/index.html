This book by [[Octavia Butler]] is the first of two that describe the fictional [[Earthseed]] religion, which helped inspire the [[SolSeedMovement]].  We give away copies of this book as part of the [[SolSeed Book Program]].  See http://en.wikipedia.org/wiki/Parable_of_the_Sower for more about the book.
