[[WikiVanning]] is similar to [[Open Space]], but typically takes place in a vehicle, where there isn't enough room for more than one session at a time. Participants write down session ideas, pick one to talk about first, then pick another one off the list when each topic seems finished. The WikiVanning style can also be used within the context of a larger event, as a way to get through several topics quickly, as with the [[WikiVanning Mind Dump]] session at the 2009 [[Longest Night Festival]].
